# Cantina

A WebGL demo of the Mos Eisley Cantina from Lego Star Wars: The Complete Saga.

- [Three.js](https://threejs.org/) / [react-three-fiber](https://github.com/pmndrs/react-three-fiber)
- [BVHEcctrl](https://github.com/pmndrs/BVHEcctrl) - character controller and collision
